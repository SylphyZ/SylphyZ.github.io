从 GMM 统一推导因子投资中的各种检验

本文从ch2第9节介绍的 GMM 框架出发，逐一推导前面各节出现的检验方法，展示它们都是 GMM 在不同矩条件和权重矩阵选择下的特例。全部推导只依赖两件工具：谱密度矩阵 $S/T$（样本均值的方差） 和 delta 方法（一阶泰勒展开）。

0. GMM 速览

矩条件： $E[\boldsymbol{f}(\boldsymbol{x}_t, \boldsymbol{b}_0)] = \boldsymbol{0}$，$n$ 个矩，$p$ 个参数。

样本矩： $\boldsymbol{g}T(\boldsymbol{b}) = \frac{1}{T}\sum{t=1}^T \boldsymbol{f}(\boldsymbol{x}_t, \boldsymbol{b})$

GMM 估计量： $\hat{\boldsymbol{b}}0 = \arg\min{\boldsymbol{b}}\ \boldsymbol{g}_T(\boldsymbol{b})'\boldsymbol{W}\boldsymbol{g}_T(\boldsymbol{b})$，或等价地 $\boldsymbol{a}\boldsymbol{g}_T(\hat{\boldsymbol{b}}_0) = \boldsymbol{0}$

谱密度矩阵： $S = \sum_{j=-\infty}^{\infty} E[\boldsymbol{f}(\boldsymbol{x}_t, \boldsymbol{b}0)\boldsymbol{f}(\boldsymbol{x}{t-j}, \boldsymbol{b}_0)']$

雅可比矩阵： $\boldsymbol{d} = E!\left[\frac{\partial \boldsymbol{f}(\boldsymbol{x}_t, \boldsymbol{b}_0)}{\partial \boldsymbol{b}'}\right]$（$n \times p$）

关键公式：

$$\text{var}(\hat{\boldsymbol{b}}_0) = \frac{1}{T}(\boldsymbol{a}\boldsymbol{d})^{-1}\boldsymbol{a}S\boldsymbol{a}'(\boldsymbol{a}\boldsymbol{d})^{-1\prime} \tag{A.1}$$

$$\text{var}(\boldsymbol{g}_T(\hat{\boldsymbol{b}}_0)) = \frac{1}{T}[\boldsymbol{I} - \boldsymbol{d}(\boldsymbol{a}\boldsymbol{d})^{-1}\boldsymbol{a}],S,[\boldsymbol{I} - \boldsymbol{d}(\boldsymbol{a}\boldsymbol{d})^{-1}\boldsymbol{a}]' \tag{A.2}$$

过度识别检验（$\boldsymbol{W} = S^{-1}$ 时）：

$$J \equiv T,\boldsymbol{g}_T(\hat{\boldsymbol{b}}_0)'S^{-1}\boldsymbol{g}_T(\hat{\boldsymbol{b}}0) \sim \chi^2{n-p} \tag{A.3}$$

以下对每种检验方法，只需做三件事：（1）写出 $\boldsymbol{f}$；（2）算出 $\boldsymbol{d}$ 和 $S$；（3）代入上面的公式。

1. 时序回归 + GRS 检验（第4.1节）

1.1 问题设定

$N$ 个资产，$K$ 个因子，因子收益率 $\boldsymbol{\lambda}_t$ 已知。对每个资产 $i$：

$$R_{it}^e = \alpha_i + \boldsymbol{\beta}_i'\boldsymbol{\lambda}t + \varepsilon{it}$$

待估参数：$\boldsymbol{b} = (\alpha_1, \boldsymbol{\beta}_1', \alpha_2, \boldsymbol{\beta}_2', \cdots, \alpha_N, \boldsymbol{\beta}_N')'$，共 $p = N(1+K)$ 个。

1.2 构造矩条件

时序回归 OLS 的一阶条件恰好可以写成矩条件。对每个资产 $i$，OLS 要求残差 $\varepsilon_{it}$ 与解释变量（常数1和 $\boldsymbol{\lambda}_t$）正交。定义 $(1+K)$ 维向量 $\boldsymbol{z}_t = (1,, \boldsymbol{\lambda}_t')'$，则资产 $i$ 贡献 $1+K$ 个矩：

$$\boldsymbol{f}_i(\boldsymbol{x}_t, \boldsymbol{b}) = \boldsymbol{z}t \cdot (R{it}^e - \alpha_i - \boldsymbol{\beta}_i'\boldsymbol{\lambda}_t) = \boldsymbol{z}t \cdot \varepsilon{it}$$

将 $N$ 个资产堆在一起，总的矩条件向量为：

$$\boldsymbol{f}(\boldsymbol{x}_t, \boldsymbol{b}) = \begin{pmatrix} \boldsymbol{z}t \varepsilon{1t} \ \boldsymbol{z}t \varepsilon{2t} \ \vdots \ \boldsymbol{z}t \varepsilon{Nt} \end{pmatrix} \in \mathbb{R}^{N(1+K)}$$

矩的个数 $n = N(1+K)$ 等于参数个数 $p = N(1+K)$，这是恰好识别（exactly identified）的情况——所有样本矩都可以精确等于零，GMM 估计量就退化为 OLS。

1.3 GMM 退化为 OLS

恰好识别时，$\boldsymbol{a}\boldsymbol{g}_T(\hat{\boldsymbol{b}}) = \boldsymbol{0}$ 就是 $\boldsymbol{g}_T(\hat{\boldsymbol{b}}) = \boldsymbol{0}$（不需要选 $\boldsymbol{a}$ 或 $\boldsymbol{W}$）。对资产 $i$，样本矩为零意味着：

$$\frac{1}{T}\sum_{t=1}^T \boldsymbol{z}t(R{it}^e - \hat{\alpha}_i - \hat{\boldsymbol{\beta}}_i'\boldsymbol{\lambda}_t) = \boldsymbol{0}$$

展开就是 $\boldsymbol{z}t'\hat{\varepsilon}{it}$ 在时序上的均值为零，即残差与解释变量正交——这正是 OLS 的正规方程。因此时序回归 OLS 就是恰好识别的 GMM。

1.4 推导参数的标准误

由于 $N$ 个资产的回归是独立的（不同资产 $i, j$ 的参数不交叉），总的 $\boldsymbol{d}$ 矩阵和 $S$ 矩阵都是分块对角的。对资产 $i$：

$$\boldsymbol{d}_i = E!\left[\frac{\partial \boldsymbol{f}_i}{\partial (\alpha_i, \boldsymbol{\beta}_i')'}\right] = -E[\boldsymbol{z}_t\boldsymbol{z}_t'] \tag{A.4}$$

$$S_i = \sum_{j=-\infty}^{\infty} E[\boldsymbol{z}t\varepsilon{it} \cdot \varepsilon_{i,t-j}\boldsymbol{z}_{t-j}'] \tag{A.5}$$

情况1：$\varepsilon_{it}$ 满足 IID。 则 $E[\varepsilon_{it}\varepsilon_{i,t-j}] = 0$（$j \neq 0$），求和只剩 $j=0$ 项：

$$S_i = E[\varepsilon_{it}^2 \boldsymbol{z}_t\boldsymbol{z}_t'] = \sigma_i^2 E[\boldsymbol{z}_t\boldsymbol{z}_t']$$

代入 $\text{var}(\hat{\boldsymbol{b}}_i) = \frac{1}{T}\boldsymbol{d}_i^{-1}S_i(\boldsymbol{d}_i^{-1})'$，注意 $\boldsymbol{d}_i^{-1} = -(E[\boldsymbol{z}_t\boldsymbol{z}_t'])^{-1}$，化简得到：

$$\text{var}\begin{pmatrix}\hat{\alpha}_i \ \hat{\boldsymbol{\beta}}_i\end{pmatrix} = \frac{\sigma_i^2}{T}(E[\boldsymbol{z}_t\boldsymbol{z}_t'])^{-1}$$

这正是经典 OLS 的协方差矩阵公式 $\sigma^2(\boldsymbol{X}'\boldsymbol{X}/T)^{-1}/T$。

情况2：$\varepsilon_{it}$ 存在异方差和/或自相关。 直接用完整的 $S_i$（式（A.5））代入，$S_i$ 的样本估计就是 Newey–West 估计量（第2.5节式（2.63））。这就解释了为什么 Newey–West 调整后的标准误是"正确的"——它对应的是 GMM 框架下对 $S$ 的正确估计。

1.5 推导 GRS 检验

GRS 想检验的是 $\alpha_1 = \alpha_2 = \cdots = \alpha_N = 0$。这是对已估参数的联合约束。

方法：追加矩条件。 在前面 $N(1+K)$ 个矩之上，追加 $N$ 个新矩来描述"$\alpha_i = 0$"这个约束。但更简洁的做法是直接从已估参数的分布出发。

由 GMM 已得到 $\hat{\alpha}_i$ 和 $\text{var}(\hat{\alpha}_i)$。将所有 $\hat{\alpha}_i$ 堆成向量 $\hat{\boldsymbol{\alpha}} = (\hat{\alpha}_1, \cdots, \hat{\alpha}_N)'$，其联合协方差矩阵为 $\text{cov}(\hat{\boldsymbol{\alpha}})$。在 $H_0: \boldsymbol{\alpha} = \boldsymbol{0}$ 下构造 Wald 统计量：

$$W = \hat{\boldsymbol{\alpha}}',[\text{cov}(\hat{\boldsymbol{\alpha}})]^{-1},\hat{\boldsymbol{\alpha}} \xrightarrow{d} \chi^2_N \tag{A.6}$$

现在推导 $\text{cov}(\hat{\boldsymbol{\alpha}})$。在恰好识别、$\varepsilon_{it}$ IID 正态的条件下，$\hat{\alpha}_i = \bar{R}_i^e - \hat{\boldsymbol{\beta}}_i'\bar{\boldsymbol{\lambda}}$，其中 $\bar{R}_i^e$ 和 $\bar{\boldsymbol{\lambda}}$ 是时序均值。利用 $\hat{\alpha}i$ 的定义和 $\varepsilon{it}$ 的正态性，可以证明：

$$\text{cov}(\hat{\boldsymbol{\alpha}}) = \frac{1}{T}\boldsymbol{\Sigma}\left(1 + \bar{\boldsymbol{\lambda}}'\hat{\boldsymbol{\Sigma}}_\lambda^{-1}\bar{\boldsymbol{\lambda}}\right) \tag{A.7}$$

其中 $\boldsymbol{\Sigma} = \text{cov}(\boldsymbol{\varepsilon}t)$（$N \times N$ 残差协方差矩阵），$\hat{\boldsymbol{\Sigma}}\lambda$ 是因子收益率的样本协方差矩阵。

代入式（A.6），并利用有限样本下 $F$ 分布与 $\chi^2$ 分布的关系做精确修正：

$$\frac{T - N - K}{N}\left(1 + \bar{\boldsymbol{\lambda}}'\hat{\boldsymbol{\Sigma}}\lambda^{-1}\bar{\boldsymbol{\lambda}}\right)^{-1}\hat{\boldsymbol{\alpha}}'\hat{\boldsymbol{\Sigma}}^{-1}\hat{\boldsymbol{\alpha}} \sim F{N,,T-N-K}$$

这正是第4.1节的 GRS 统计量（式（2.16））。

小结：GRS 检验 = 时序回归 GMM 估计量的 Wald 检验 + IID 正态下的有限样本精确分布修正。

2. 截面回归（第4.2节）

2.1 问题设定

第一步时序回归（与上节相同）得到 $\hat{\boldsymbol{\beta}}_i$。第二步将 $\hat{\boldsymbol{\beta}}_i$ 视为已知，在截面上估计 $\boldsymbol{\lambda}$。

2.2 构造矩条件

截面回归也可以放入 GMM。关键是把两步合在一起。总共有两组矩条件：

第一组（$N(1+K)$ 个矩）： 时序回归的 OLS 正规方程——与第1节完全相同。

第二组（$K$ 个矩）： 截面回归 OLS 的一阶条件。定义截面残差 $\alpha_{it} = R_{it}^e - \hat{\boldsymbol{\beta}}_i'\boldsymbol{\lambda}_t$。OLS 要求 $\hat{\boldsymbol{\beta}}i$ 与 $\alpha{it}$ 在截面上正交，写成时序均值的矩条件：

$$E!\left[\frac{1}{N}\sum_{i=1}^N \hat{\boldsymbol{\beta}}i(R{it}^e - \hat{\boldsymbol{\beta}}_i'\boldsymbol{\lambda}_t)\right] = \boldsymbol{0}$$

即 $E[\hat{\boldsymbol{\beta}}'(\boldsymbol{R}_t^e - \hat{\boldsymbol{\beta}}\boldsymbol{\lambda}_t)] = \boldsymbol{0}$，这正是 $(\hat{\boldsymbol{\beta}}'\hat{\boldsymbol{\beta}})^{-1}\hat{\boldsymbol{\beta}}'E_T[\boldsymbol{R}^e]$ 的一阶条件。

总的参数向量 $\boldsymbol{b} = (\alpha_1, \boldsymbol{\beta}_1', \cdots, \alpha_N, \boldsymbol{\beta}_N', \boldsymbol{\lambda}')'$，参数个数 $p = N(1+K) + K$。矩的个数 $n = N(1+K) + K = p$，仍是恰好识别。

2.3 推导标准误——Shanken 修正的来源

关键在于 $\hat{\boldsymbol{\lambda}}$ 的方差。由于第二步用了第一步估计的 $\hat{\boldsymbol{\beta}}_i$（生成的回归变量），$\hat{\boldsymbol{\lambda}}$ 的方差中会出现来自 $\hat{\boldsymbol{\beta}}_i$ 估计误差的额外项。

在 GMM 框架下，$\hat{\boldsymbol{\lambda}}$ 只是总参数向量 $\hat{\boldsymbol{b}}$ 的一部分。GMM 自动地对全部参数联合计算协方差矩阵，天然包含了两步之间的误差传播。从式（A.1）出发，取出 $\hat{\boldsymbol{\lambda}}$ 对应的分块，并在 IID 假设下化简，最终得到：

$$\text{cov}(\hat{\boldsymbol{\lambda}}) = \frac{1}{T}\left[(\hat{\boldsymbol{\beta}}'\hat{\boldsymbol{\beta}})^{-1}\hat{\boldsymbol{\beta}}'\boldsymbol{\Sigma}\hat{\boldsymbol{\beta}}(\hat{\boldsymbol{\beta}}'\hat{\boldsymbol{\beta}})^{-1}(1 + \boldsymbol{\lambda}'\boldsymbol{\Sigma}_f^{-1}\boldsymbol{\lambda}) + \boldsymbol{\Sigma}_f\right]$$

这正是第2.7节的 Shanken 修正公式（式（2.24））。其中 $(1 + \boldsymbol{\lambda}'\boldsymbol{\Sigma}_f^{-1}\boldsymbol{\lambda})$ 这个修正系数并非人为添加，而是 GMM 联合估计两步参数时自然产生的结果。

小结：Shanken 修正不是一个独立的"补丁"，而是 GMM 对两步回归估计自动给出的正确标准误。

2.4 推导 $\chi^2$ 检验

$H_0: \boldsymbol{\alpha} = \boldsymbol{0}$。样本矩中对应 $\alpha_i$ 的部分就是截面回归残差。利用 GMM 的过度识别检验（式（A.3）），或直接用 Wald 统计量：

$$\hat{\boldsymbol{\alpha}}',[\text{cov}(\hat{\boldsymbol{\alpha}})]^{-1},\hat{\boldsymbol{\alpha}} \sim \chi^2_{N-K}$$

这正是第4.2节式（2.30）和（2.31）。OLS 和 GLS 版本的区别仅在于选择了不同的 $\boldsymbol{W}$（或 $\boldsymbol{a}$）：OLS 对应 $\boldsymbol{W} = \boldsymbol{I}$，GLS 对应 $\boldsymbol{W} = \boldsymbol{\Sigma}^{-1}$。

3. Fama–MacBeth 回归（第4.4节）

3.1 问题设定

和截面回归相同的两步结构，但第二步在每个 $t$ 做一次截面 OLS，共 $T$ 次，再将 $T$ 个估计取平均。

3.2 GMM 视角

Fama–MacBeth 的本质是：对于每个 $t$，用 $N$ 个资产的截面数据 $(R_{1t}^e, \cdots, R_{Nt}^e)$ 和 $\hat{\boldsymbol{\beta}}_i$，跑一次截面 OLS 得到 $\hat{\boldsymbol{\lambda}}_t$。然后：

$$\hat{\boldsymbol{\lambda}} = \frac{1}{T}\sum_{t=1}^T \hat{\boldsymbol{\lambda}}_t$$

这就是一个样本均值。而 GMM 的核心正是处理样本均值的方差。

将每一期的截面 OLS 估计量写出来：

$$\hat{\boldsymbol{\lambda}}_t = (\hat{\boldsymbol{\beta}}'\hat{\boldsymbol{\beta}})^{-1}\hat{\boldsymbol{\beta}}'\boldsymbol{R}_t^e$$

定义 $\boldsymbol{u}_t = \hat{\boldsymbol{\lambda}}_t - \boldsymbol{\lambda}$（围绕真值的偏差）。当 $\hat{\boldsymbol{\beta}}$ 在时序上不变时，$\hat{\boldsymbol{\lambda}}$ 的方差就是 $\boldsymbol{u}_t$ 的样本均值的方差。这正是第9.1节的基本问题。

3.3 推导标准误

Fama–MacBeth 的做法： 直接用 $T$ 个 $\hat{\boldsymbol{\lambda}}_t$ 的时序样本方差估计 $\text{var}(\hat{\boldsymbol{\lambda}})$：

$$\text{cov}(\hat{\boldsymbol{\lambda}}) = \frac{1}{T^2}\sum_{t=1}^T (\hat{\boldsymbol{\lambda}}_t - \hat{\boldsymbol{\lambda}})(\hat{\boldsymbol{\lambda}}_t - \hat{\boldsymbol{\lambda}})'$$

这等价于用 $\hat{\boldsymbol{\lambda}}_t$ 的样本方差除以 $T$，即 $\hat{S}/T$ 的最简单版本——假设 $\hat{\boldsymbol{\lambda}}_t$ 无自相关（$j \neq 0$ 时 $\text{cov}(\boldsymbol{u}t, \boldsymbol{u}{t-j}) = 0$）。

在 GMM 的谱密度矩阵语言下：

$$S_{\text{FM}} = E[\boldsymbol{u}_t\boldsymbol{u}_t'] = \text{var}(\hat{\boldsymbol{\lambda}}_t)$$

$$\text{var}(\hat{\boldsymbol{\lambda}}) = S_{\text{FM}} / T$$

Fama–MacBeth 排除截面相关性的机制： 传统截面回归对时序平均 $E_T[\boldsymbol{R}^e]$ 做一次回归，$\alpha_i$ 之间的截面相关性直接影响标准误。Fama–MacBeth 在每个 $t$ 独立做截面回归，截面相关性被"封装"在每期的 $\hat{\boldsymbol{\lambda}}_t$ 内部，然后通过 $\hat{\boldsymbol{\lambda}}_t$ 的时序波动自然地反映出来。在 GMM 框架下，这对应于选择了一个特殊的分块结构的 $S$ 矩阵，使截面相关性不出现在 $\text{var}(\hat{\boldsymbol{\lambda}})$ 的表达式中。

3.4 不足之处的 GMM 解释

时序自相关： Fama–MacBeth 用的 $S_{\text{FM}}$ 只包含 $j=0$ 项。如果 $\hat{\boldsymbol{\lambda}}t$ 存在时序自相关，需要用完整的谱密度矩阵（即 Newey–West 版本的 $S$）代替。这就是第4.4节提到的"对 $\alpha{it}$ 时序相关性无能为力"的数学本质。

生成回归变量： $\hat{\boldsymbol{\beta}}_i$ 是估计值。Fama–MacBeth 在计算 $\text{var}(\hat{\boldsymbol{\lambda}})$ 时没有考虑 $\hat{\boldsymbol{\beta}}_i$ 的误差。在完整的 GMM 框架下（把两步合在一起），这个误差会自动传播到 $\text{cov}(\hat{\boldsymbol{\lambda}})$ 中，产生 Shanken 修正项。

小结：Fama–MacBeth = GMM 框架下对 $S$ 做了"无时序自相关"的简化估计 + 忽略了生成回归变量的误差传播。

4. 异象的时序回归检验 + Newey–West（第6.2节）

4.1 问题设定

异象收益率 $R_t^e$ 对 $K$ 个因子做时序回归：

$$R_t^e = \alpha + \boldsymbol{\beta}'\boldsymbol{\lambda}_t + \varepsilon_t$$

检验 $H_0: \alpha = 0$。

4.2 GMM 矩条件

这是单个资产的时序回归，和第1节中的一个资产完全一样。矩条件：

$$\boldsymbol{f}(\boldsymbol{x}_t, \boldsymbol{b}) = \boldsymbol{z}_t \varepsilon_t = \begin{pmatrix} 1 \ \boldsymbol{\lambda}_t \end{pmatrix}(R_t^e - \alpha - \boldsymbol{\beta}'\boldsymbol{\lambda}_t)$$

$n = 1 + K$ 个矩，$p = 1 + K$ 个参数（$\alpha$ 和 $\boldsymbol{\beta}$），恰好识别。

4.3 推导标准误

$$\boldsymbol{d} = -E[\boldsymbol{z}t\boldsymbol{z}t'], \quad S = \sum{j=-\infty}^{\infty} E[\boldsymbol{z}t\boldsymbol{z}{t-j}'\varepsilon_t\varepsilon{t-j}]$$

$$\text{var}(\hat{\boldsymbol{b}}) = \frac{1}{T}(E[\boldsymbol{z}_t\boldsymbol{z}_t'])^{-1} S, (E[\boldsymbol{z}_t\boldsymbol{z}_t'])^{-1}$$

这就是第2.5节的 Newey–West 三明治公式（式（2.64））：$\hat{\boldsymbol{V}}_{\text{OLS}} = T(\boldsymbol{X}'\boldsymbol{X})^{-1}\boldsymbol{S}(\boldsymbol{X}'\boldsymbol{X})^{-1}$。

$S$ 的样本估计就是式（2.63）的 Newey–West 估计量。取出 $\hat{\alpha}$ 对应的对角线元素开方，即为 $\text{s.e.}(\hat{\alpha})$，计算 $t$-值完成检验。

小结：Newey–West 调整后的 $t$-值 = GMM 框架下使用完整谱密度矩阵 $S$ 计算的 Wald 检验 $t$-值。

5. 对单一收益率序列的检验（第2.6节）

5.1 问题设定

检验因子（或异象）收益率序列 ${\lambda_t}$ 的均值是否显著不为零。

5.2 GMM 矩条件

这是最简单的 GMM。只有 $n = 1$ 个矩、$p = 1$ 个参数（均值 $\mu$）：

$$f(x_t, \mu) = \lambda_t - \mu$$

矩条件 $E[\lambda_t - \mu] = 0$ 意味着 $\mu = E[\lambda_t]$。

5.3 推导

$$d = \frac{\partial f}{\partial \mu} = -1, \quad S = \sum_{j=-\infty}^{\infty} E[(\lambda_t - \mu)(\lambda_{t-j} - \mu)]$$

$$\text{var}(\hat{\mu}) = \frac{S}{T}$$

$S$ 的 Newey–West 估计量就是第2.6节式（2.66）：

$$\hat{S} = \frac{1}{T}\left{\sum_{t=1}^T \hat{\varepsilon}t^2 + 2\sum{j=1}^J \sum_{t=j+1}^T w_j \hat{\varepsilon}t \hat{\varepsilon}{t-j}\right}$$

其中 $\hat{\varepsilon}_t = \lambda_t - \bar{\lambda}$。因此 $\text{s.e.}(\hat{\mu}) = \sqrt{\hat{S}/T}$（式（2.67））。

小结：这是 GMM 最退化的情况——一个矩、一个参数。谱密度矩阵 $S$ 退化为标量，就是 Newey–West 调整后的"长期方差"。

6. 截面回归的 $\chi^2$ 检验（第4.2节式（2.30）（2.31））

6.1 GMM 推导

截面回归估计了 $K$ 个 $\hat{\lambda}_k$ 和 $N$ 个 $\hat{\alpha}_i$。检验 $H_0: \boldsymbol{\alpha} = \boldsymbol{0}$。

在 GMM 框架下，$\hat{\boldsymbol{\alpha}}$ 就是评估样本矩的残差。过度识别检验（式（A.3））直接给出：

$$T,\hat{\boldsymbol{\alpha}}',[\text{var}(\hat{\boldsymbol{\alpha}})]^{-1},\hat{\boldsymbol{\alpha}} \sim \chi^2_{N-K}$$

自由度 $N - K$：$N$ 个资产的定价误差被 $K$ 个因子收益率参数"消耗"了 $K$ 个自由度。

OLS 版本： 对应 GMM 中 $\boldsymbol{W} = \boldsymbol{I}$（或等价地 $S$ 中用 $\boldsymbol{\Sigma}$ 的对角结构），$\text{cov}(\hat{\boldsymbol{\alpha}})$ 如式（2.23）（加 Shanken 修正如式（2.25）），代入得到式（2.30）。

GLS 版本： 对应 GMM 中 $\boldsymbol{W} = \boldsymbol{\Sigma}^{-1}$，$\text{cov}(\hat{\boldsymbol{\alpha}}_{\text{GLS}})$ 如式（2.29），代入得到式（2.31）。

小结：OLS 截面检验和 GLS 截面检验是 GMM 过度识别检验在不同权重矩阵下的特例。GLS 对应有效 GMM（$\boldsymbol{W} = S^{-1}$）。

7. Fama–MacBeth 的 $\chi^2$ 检验（第4.4节式（2.44））

直接从 Fama–MacBeth 得到 $\hat{\boldsymbol{\alpha}}$ 和 $\text{cov}(\hat{\boldsymbol{\alpha}})$（式（2.42）（2.43）），构造：

$$\hat{\boldsymbol{\alpha}}',\text{cov}(\hat{\boldsymbol{\alpha}})^{-1},\hat{\boldsymbol{\alpha}} \sim \chi^2_{N-K}$$

在 GMM 框架下，这仍然是 Wald 检验。与截面回归版本的区别仅在于 $\text{cov}(\hat{\boldsymbol{\alpha}})$ 的估计方式不同：

  • 截面回归用解析公式（依赖 $\boldsymbol{\Sigma}, \boldsymbol{\Sigma}_f$ 的估计 + Shanken 修正）。
  • Fama–MacBeth 直接用 $\hat{\boldsymbol{\alpha}}_t$ 的时序样本协方差（天然吸收截面相关性，但忽略时序相关性和生成变量误差）。

8. 均值—方差张成检验（第7.3节）

8.1 GMM 矩条件

考虑 $K$ 个因子 $R_{1t}$ 和 $N$ 个测试资产 $R_{2t}$，回归模型：

$$R_{2t} = \boldsymbol{\alpha} + \boldsymbol{\beta} R_{1t} + \boldsymbol{\varepsilon}_t$$

定义 $\boldsymbol{\delta} = \mathbf{1}_N - \boldsymbol{\beta}\mathbf{1}_K$。矩条件对应回归的 OLS 正规方程：

$$\boldsymbol{f}(\boldsymbol{x}t, \boldsymbol{b}) = \begin{pmatrix} 1 \ R{1t} \end{pmatrix} \otimes \boldsymbol{\varepsilon}_t$$

$n = N(1+K)$ 个矩，$p = N(1+K)$ 个参数（每个测试资产有 $1 + K$ 个回归系数），恰好识别。

8.2 原假设与检验

原假设 $H_0: \boldsymbol{\alpha} = \boldsymbol{0}_N,, \boldsymbol{\delta} = \boldsymbol{0}_N$ 是对 $2N$ 个参数的约束。由 $\boldsymbol{\delta} = \mathbf{1}_N - \boldsymbol{\beta}\mathbf{1}_K$，约束可统一写成 $\boldsymbol{R}\boldsymbol{b} = \boldsymbol{r}$ 的形式。

在 GMM 框架下，用 Wald 检验：

$$W = (\boldsymbol{R}\hat{\boldsymbol{b}} - \boldsymbol{r})',[\boldsymbol{R},\text{var}(\hat{\boldsymbol{b}}),\boldsymbol{R}']^{-1},(\boldsymbol{R}\hat{\boldsymbol{b}} - \boldsymbol{r}) \xrightarrow{d} \chi^2_{2N}$$

在正态 IID 假设下，这个 $\chi^2_{2N}$ 统计量恰好可以分解为两个分量 $s_1$ 和 $s_2$ 的函数（对应纵轴上两个特殊的 $r$ 值），从而退化为第7.3节式（2.76）的 Wald 形式 $W = T(s_1 + s_2)$。

类似地，似然比检验和拉格朗日乘数检验是 GMM 框架下检验约束条件的三种渐进等价方法，它们在有限样本下略有差异，但大样本下都趋于 $\chi^2_{2N}$。

小结：均值—方差张成检验的三种统计量 = 对时序回归 GMM 参数施加 $H_0: \boldsymbol{\alpha} = \boldsymbol{0}, \boldsymbol{\delta} = \boldsymbol{0}$ 约束的 LR / Wald / LM 检验。

一切检验的底层逻辑只有一个：

$$\text{var}(\text{样本均值}) = \frac{S}{T}$$

不同检验方法的区别仅在于：（1）选择了什么矩条件 $\boldsymbol{f}$；（2）选择了什么权重矩阵 $\boldsymbol{W}$（或 $\boldsymbol{a}$）；（3）对 $S$ 做了什么近似（IID、仅异方差、HAC 完整版）。GMM 提供了统一的语言和推导框架，将看似各异的方法串联在一起。
